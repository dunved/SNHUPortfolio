CS 465: During this comprehensive full stack project, I utilized both server-side rendered HTML pages with Express and a single-page application (SPA) approach using JavaScript for the frontend. The Express HTML pages provided clear routing and server-side rendering, while the SPA enhanced user experience through dynamic content updates without page reloads. For the backend, I chose MongoDB as the NoSQL database due to its flexible, document-based structure, which seamlessly accommodated JSON-like data objects that aligned well with JavaScript.&nbsp;JSON served as the primary data-interchange format between the frontend and backend, facilitating efficient communication through API endpoints. Unlike JavaScript, which is a full-fledged programming language, JSON's simplicity as a pure data format made it ideal for system-to-system communication. Throughout the project, I focused on code refactoring, separating routes, controllers, and UI components to improve organization, readability, and efficiency while minimizing code duplication.&nbsp;Rigorous testing was crucial to ensure the application's reliability and security. I thoroughly tested API endpoints using various HTTP methods (GET, POST, PUT, DELETE) to verify proper data handling and implemented authentication and authorization for protected admin routes. The addition of login security introduced new challenges, requiring extensive testing of middleware, token validation, and error handling to prevent unauthorized access.&nbsp;This project significantly enhanced my understanding of full stack architecture, RESTful API design, database integration, and secure authentication practices. These newly acquired skills have brought me closer to my goal of becoming a backend developer by improving my ability to design secure, scalable applications and increasing my competitiveness in the software development industry. The hands-on experience gained through this project has been invaluable in solidifying my knowledge and preparing me for real-world development scenarios.
